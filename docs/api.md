# Receivables Platform - API Specification

## Standards

- **Protocol**: RESTful JSON over HTTPS.
- **Base URI**: `/api/v1`
- **Interactive Documentation**: Swagger / OpenAPI available at `/api/docs`.
- **Correlation**: `X-Request-ID` header accepted or generated by server (`req_<uuid>`).

## Standard Error Response Format

```json
{
  "statusCode": 409,
  "code": "RECEIVABLE_ALREADY_PAID",
  "message": "The receivable has already been fully paid.",
  "requestId": "req_88291a2b",
  "timestamp": "2026-09-27T10:45:12.000Z",
  "path": "/api/v1/receivables/rec_1/cancel"
}
```

## Health Endpoints

- `GET /health`: Overall service uptime and status
- `GET /health/live`: Process liveness probe
- `GET /health/ready`: PostgreSQL and Redis readiness probe
